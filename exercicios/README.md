# Exercícios

Guarde aqui apenas programas próprios, pequenos e educativos. Prefira nomes que indiquem o conceito, por exemplo `01-soma-par.c` e `02-ponteiros.c`.

Os exercícios estão separados por dia. Cada exercício mantém o enunciado e uma única resposta atual do aluno. Quando o código for corrigido, a resposta atual é substituída; tentativas intermediárias não são registradas.

Compilação inicial:

```bash
gcc -Wall -Wextra -std=c17 arquivo.c -o programa
./programa
```
